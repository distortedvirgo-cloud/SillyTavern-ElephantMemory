# 🐘 Elephant Memory для SillyTavern

Автоматическая память для долгих ролевых игр. Дорогая модель (рассказчик) получает короткое окно последних сообщений и сжатую память, а всю служебную работу делает дешёвая модель. Запрос к рассказчику остаётся примерно одного размера, сколько бы ни длился чат.

## Как это работает

| Слой | Кто делает | Когда |
|---|---|---|
| **Окно** — последние N сообщений дословно | — | всегда |
| **Сводки сцен** — выпавшие из окна сообщения сжимаются блоками | дешёвая модель | каждые 10 сообщений (настраивается) |
| **Главы** — старые сводки сцен сливаются в одну | дешёвая модель | когда сцен больше 10 |
| **Карточка состояния** — место, кто рядом, отношения, факты, обещания, сюжетные линии, предметы | дешёвая модель | каждые 6 сообщений |
| **Рыбка** — свежий вызов без истории проверяет карточку на потери и выдумки, найденное исправляется | дешёвая модель (можно отдельную) | при каждом обновлении карточки |
| **Проверка ответов** (по желанию) — рыбка ищет жёсткие противоречия в ответе рассказчика | дешёвая модель | после каждого ответа |

Всё происходит автоматически в фоне, после ответа рассказчика. Сообщения, уже покрытые сводками, исключаются только из промпта — в чате они остаются, ничего не удаляется.

Последнее сообщение не обрабатывается, пока вы не ответите: его ещё можно свайпнуть.

Порядок промпта подобран под кэширование: сводки стоят в начале и меняются редко, карточка состояния вставляется близко к концу чата (глубина 4), поэтому её обновление не сбрасывает кэш всей истории.

## Установка

1. Распакуйте папку `SillyTavern-ElephantMemory` в
   `SillyTavern/data/default-user/extensions/`
   (или в `SillyTavern/public/scripts/extensions/third-party/` — для всех пользователей).
2. Перезагрузите страницу SillyTavern.
3. Откройте панель расширений (значок кубиков) — там появится блок **🐘 Elephant Memory**.

## Настройка с NanoGPT

NanoGPT поддерживается в SillyTavern как источник Chat Completion, расширение работает с ним через профили Connection Manager.

1. **Профиль рассказчика.** API → Chat Completion → NanoGPT, выберите вашу основную модель. В Connection Manager сохраните профиль, например «Рассказчик».
2. **Профиль летописца.** Не меняя API, выберите дешёвую модель (DeepSeek, GLM, Gemini Flash и т.п.) и сохраните второй профиль — «Летописец». Затем снова переключитесь на «Рассказчик».
3. В Elephant Memory выберите «Летописец» в поле **Служебная модель**. Поле **Рыбка-критик** можно оставить пустым или выбрать модель посильнее — более сильный критик ловит больше ошибок.
4. Если у вас подписка NanoGPT, проверьте, входит ли в неё выбранная служебная модель: тогда служебные вызовы почти ничего не стоят.

Если профиль не выбран, служебные вызовы пойдут через основную модель — расширение предупредит об этом.

### Кэш для моделей Claude через NanoGPT

В `SillyTavern/config.yaml`:

```yaml
claude:
  enableSystemPromptCache: true
```

Перезапустите SillyTavern. Для моделей Claude через NanoGPT SillyTavern тогда сам добавляет параметр кэширования в запрос. Учтите: у NanoGPT явное кэширование Claude оплачивается по pay-as-you-go и не покрывается подпиской. Для моделей OpenAI, Gemini и многих открытых NanoGPT кэширует автоматически, ничего включать не нужно.

## Старые длинные чаты

При первом открытии длинного чата расширение не станет сжимать всё разом, чтобы не потратить деньги без спроса: оно сжимает по 2 блока за ход и предложит **«Пересобрать память»**. Кнопка сожмёт весь чат сразу и покажет примерное число вызовов перед стартом. Кнопка **«Стоп»** прерывает процесс после текущего вызова.

## Ручная правка

Карточку состояния, сводки сцен и главы можно править прямо в панели. Исправления сразу попадают в промпт. Сводки сохраняют маркеры вида `[0-10]` (диапазон сообщений) и разделитель `=====` — не удаляйте их.

## Команды

- `/em-update` — обновить память и карточку сейчас
- `/em-rebuild` — пересобрать память с нуля
- `/em-state` — вывести текущую карточку (можно использовать в STscript)

## Сколько это стоит

На каждые 10 сообщений: 1 вызов для сводки сцены и 1–2 обновления карточки (по 1–3 вызова с проверкой рыбкой). Всё это — дешёвая модель с небольшим контекстом. Взамен каждый запрос к дорогой модели не тащит за собой всю историю чата. В панели показано, сколько токенов старой истории заменено памятью на каждом запросе.

Проверка ответов в режиме «Перегенерировать» может вызвать дорогую модель повторно — лимит попыток настраивается (по умолчанию 1).

## Ограничения версии 0.1

- Логика памяти проверена автотестами, но первый запуск в живом SillyTavern — ваш. Если что-то не так, откройте консоль браузера (F12) и пришлите строки с `[Elephant Memory]`.
- В групповых чатах не тестировалось.
- Если удалить или отредактировать уже сжатые сообщения, расширение предупредит и предложит пересобрать память.
- Промпты служебной модели можно менять в «Продвинутых настройках».
